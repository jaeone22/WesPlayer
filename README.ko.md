# WesPlayer
옆사람이 내가 듣는 음악의 정보를 볼수 없게 하기 위해 설계된 웹 음악 플레이어.
그 어떠한 정보도 브라우저/서버로 저장되지 않습니다.

# 사용법
1. 업로드 버튼을 클릭하여 오디오나 비디오 파일을 업로드합니다.
   - 영상은 기본적으로 숨겨져 있으며 Show 버튼을 눌러 표시할수 있습니다.
2. 음악을 즐기세요!

# 모든 기능들
- 음악 재생 (브라우저가 지원하는 모든 포맷)
- 영상 재생(브라우저가 지원하는 모든 포맷)
- 재생목록
- 셔플
- 파일 업로드
- 음량 조절 (비선형 파워 매핑 방식)
